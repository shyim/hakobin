# Hakobin Docs

Operational guides for publishing package repositories with Hakobin.

- [APT repository setup](apt-setup.md): initialize an APT repository, upload `.deb` packages, and configure clients.
- [Signing key publication](signing-keys.md): how Hakobin publishes public keys for APT and RPM repositories.
- [Key rotation](key-rotation.md): rotate to a new signing key without breaking existing clients.
